# test_repository

Testovací repozitář pro zkoušení práce s Gitem, GitHubem a Claude Code.

## Účel

Repozitář slouží k vyzkoušení běžného vývojového postupu:

- vytváření a úpravy souborů,
- commitování změn a práce s větvemi,
- otevírání a slučování pull requestů.

Neobsahuje žádný produkční kód. Jeho obsah se může kdykoli změnit nebo smazat.
